# Diary — 2026-11-02 (01)

## Complete JSON Lines of a stream still being written

Litmus watches Swift Testing's event stream while the tests run, to stop at the first failure. The file grows as it is
read, so its last line can be half a record; `ndjsonLines` returns that half, and parsing it fails for a reason that is
not one. `ndjsonCompleteLines(_:)` returns only the lines a `\n` ends and the offset past the last one, so a reader keeps
the rest and reads on from there. Same splitting and trimming as `ndjsonLines`, one pass, no copy beyond the records.

Pins: aemi 6ed7fb7 (its ADR 0028), AemiRegex cc7deea. 509 tests pass.
