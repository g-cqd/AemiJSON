# Diary — 2026-10-30 (01)

## Coding paths from the root (roadmap 0005)

Coding errors now carry the path from the root, as Foundation's do: the decoder prefixes the member, index or field as an error passes up,
and the encoder keeps its own path. The probes stayed within 1–2% of the base. Absolute `codingPath` reads inside `init(from:)` are not done.
Along the way the `@JSONCodable` readers turned out to report a wrong type as a missing key and to swallow it in the `IfPresent` forms; that
became roadmap 0009.

## AemiJSONRPC (roadmap 0006)

JSON-RPC 2.0 for the family, from swift-search's `LSPFrame`, `LanguageServerConnection` and `MCPStdio`, with ask's `AskMCP` lessons:
`memchr` for every delimiter, scanning only the new bytes, never scanning a body. The first header-scan measurement was 0.96 GB/s, under the
5 GB/s bar, because finding the `Content-Length` line still walked the header byte by byte; using `memchr` per line brought it to 5.8–6.1.

The suite hung when run whole and passed test by test. Sampling the helper showed only an idle main thread: no lock, no busy loop, a
continuation nobody would resume. Two tests built their scripted peer with Content-Length framing while the connection wrote lines, so the
peer never saw the request it was waiting to see. The fix was in the tests; the connection suite now has a one-minute limit so the next
lost continuation fails by name. Lesson: `swift test` buffers the helper's output until it exits, and `timeout` kills `swift test` but
leaves `swiftpm-testing-helper` behind; look for orphans before reading a hang as a deadlock.

## Remote state

Before pushing, every repository touched was fetched. AemiRegex had four upstream commits, each an aemi pin bump for MacFS, and aemi's
local `main` was twelve behind; both fast-forwarded with no conflict. AemiJSON's remote had not moved. The pins diverging across the family
became roadmap 0010.

## The gates are green again without loosening them

A review of ask's dependency update found two problems on main that predate it. Some duplicated-code warnings, and one
test slightly over the 100 ms type-check budget, so its tests needed `AD_TYPECHECK_BUDGET_MS=250` locally.

Building the tests with a lower budget (25 to 50 ms) lists every slow body with its time, whatever the load. Three were
mine, and all three were over or near the limit: the pipe test of AemiJSONRPC (102 ms, a closure in a `Thread`
initializer), a coding-path test (113 ms, dictionary literals inferred inside a generic call) and a JSON5 lexeme test
(88–90 ms, five enum comparisons inside `#expect`). Typed helpers and a typed table bring them under 25 to 50 ms. Three
builds at the default budget passed at load averages of 84 to 118.

The 13 dolly warnings were all in the Codable hot path. Seven were real repetition: the fast cursor's ten readers, the
decoder's four number readers and four keyed scalars, and the encoders' three-line integer methods. Each became a shared
`@inline(__always)` helper. The six left are the ten integer requirements of each Codable container, one line each,
which the protocols force. They are accepted with a `@dolly:disable near-clone -- reason` region, as the script asks,
not with a baseline entry. The probes retired the same instructions before and after (within 0.1% in each mode), so the
refactor costs nothing. Wall times at load 110–130 were noise both ways.
