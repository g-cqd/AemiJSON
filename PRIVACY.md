# Privacy Policy

`AemiJSON` is an open-source Tape-based JSON, JSON5, JSON Schema, JSONPath, JSON Pointer/Patch, and JSON-RPC library for Swift, licensed under the MIT License.

## Data Collection and Telemetry

- **No telemetry or analytics:** `AemiJSON` collects, stores, and transmits **zero** telemetry, usage analytics, crash reports, or personal data.
- **No network access:** `AemiJSON` performs no outbound network requests and contains no tracking, licensing, or phone-home logic.

## Data Processed Locally

As a compiled Swift library, `AemiJSON` processes only the in-memory inputs and local filesystem paths provided directly by the host application or tool that links it.

## GDPR and Enterprise Compliance

`AemiJSON` operates strictly within the calling process and transmits no data to external services.
